CMMC Security Auditor Toolkit

A lightweight, on-premises-friendly PowerShell toolkit that performs automated security audits of Microsoft stack environments to support CMMC Level 2 technical controls.

✨ What This Tool Does

This toolkit audits:

  • IIS Web Servers
  • Microsoft SQL Server Instances
  • Windows Operating Systems

It generates easy-to-read HTML reports summarizing security findings mapped to CMMC Level 2 requirements.

No installation required. All scripts are local-only. No cloud dependencies.

🔍 Summary of What is Audited

IIS (Internet Information Services)

  • HTTPS Redirect enforced
  • HSTS (HTTP Strict Transport Security) headers
  • TLS 1.2 enabled, TLS 1.0 disabled
  • IIS Logging enabled
  • applicationHost.config file permissions

Microsoft SQL Server

  • 'sa' account disabled
  • Transparent Data Encryption (TDE) enabled on databases
  • Recent backups are encrypted
  • Detection of elevated SQL logins
  • SQL Server Audit configuration validated

Windows Server / Windows OS

  • Audit Policy settings
  • Windows Firewall profile status
  • Account Lockout Policy (threshold, duration, window)

📋 Deliverables

  • Clear HTML Audit Report
  • CMMC Control Mapping table
  • Raw JSON Output for technical evidence

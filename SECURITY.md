# Security Policy

## Supported Versions

This tool was built to support **offline, on-premises environments** in line with **CMMC Level 2** guidelines.

## Reporting a Vulnerability

If you discover a vulnerability; do not create a public GitHub issue.

## Secure Usage

- Tool runs entirely offline.
- No internet connectivity is required or used.
- Ensure PowerShell execution policies allow for signed scripts if used in production.

This tool is intended for technical audits in **non-cloud**, **local-only Microsoft stack environments**.
